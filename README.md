# ASTRO'

The website for the music artist ASTRO'.

**See it live:** https://kxngcxzz.github.io/Astro-Music-Artist-Landing-Page/

## What's on it

- **Latest release** — the newest single, with buttons through to every platform
- **Releases** — the back catalogue, one cover at a time
- **The artist** — photos and the biography
- **Unreleased** — snippets you can play before they come out
- **Bookings** — email buttons for shows, features and press
- **Listen** — Spotify, Apple Music, SoundCloud and YouTube

## How it works

The whole site is one file: `index.html`. The photos, the covers and the
video are all stored inside it, so there is nothing to install and nothing
else to upload. Put that one file on any web host and the site works. Open
it straight off a USB stick and it still works.

That is why the file is around 12MB. For a site carrying this much video
that is normal.

`thumb.jpg` is the picture that shows up when somebody shares the link.

## If the address changes

When ASTRO' gets his own domain, the old address needs swapping in four
places: three near the top of `index.html` (the lines with `og:url`,
`og:image` and `twitter:image`) and the link at the top of this file.
Change those and the link previews carry on working.
